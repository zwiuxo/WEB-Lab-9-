**📌 Описание задания**
- Настройка автоматического пайплайна непрерывной интеграции через **GitHub Actions**.
- Использование Docker внутри облачной CI-среды для изоляции тестов.
- Автоматический запуск **PHPUnit** при каждом коммите в репозиторий.

**🚨 Штрафное задание**
1. **Multi-job Pipeline:** Процесс разделен на два независимых этапа: `build`  и `test` 
2. **Мониторинг сервисов:** Добавлен шаг `Check Container Status` (`docker ps`) и ожидание готовности базы данных (`sleep 15`).
3. **Логирование ошибок:** Реализован вывод логов контейнера при падении тестов через `if: failure()`.
4. **Изоляция окружения:** Использование файла `.env.test` для настройки параметров подключения внутри CI.
5. **Автоматизация зависимостей:** Установка Composer-пакетов интегрирована в CI-процесс.

**📊 Результат**
Проект успешно проходит все этапы проверки. Реализована современная методология DevOps, обеспечивающая контроль качества кода в автоматическом режиме.
